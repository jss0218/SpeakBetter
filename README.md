# Podium — AI Public Speaking Coach

> Built for LA Hacks 2026 · Fetch.ai Agentverse Prize Track

Podium puts you in front of a live, reactive virtual audience and coaches you in real time. It doesn't just transcribe what you say — it watches how you say it, tracks your body language, finds the weakest point in your argument, and challenges you with a hard question before your session ends. When you're done, you get a full breakdown and a coach you can keep talking to through ASI:One.

---

## The Problem

Most people practice speeches alone, with no feedback and no pressure. When the real moment comes — a pitch, an interview, a presentation — the nerves hit differently. Podium trains you in conditions that actually feel like the room.

---

## What It Does

### Live Audience Simulation
A grid of AI avatars reacts emotionally to your delivery in real time. Their expressions shift based on your engagement score — how your voice, pacing, and eye contact land together. This creates the psychological pressure of a real audience without needing one.

### Real-Time Speech Analysis
Every 30 seconds of speech is analyzed for:
- **Filler words** — "um", "uh", "like", "you know" counted and flagged
- **Pace (WPM)** — words per minute tracked continuously
- **Vocal energy** — delivery strength inferred from transcript density and timing

### Computer Vision Delivery Tracking
Your webcam feed is analyzed frame-by-frame using facial landmark detection:
- **Eye contact score** — how directly you face the camera vs. looking away
- **Posture score** — head position, tilt, and roll relative to your calibrated baseline
- **Facial expression** — brow furrow, smile score, and overall expressiveness
- **Motion score** — gesture activity and movement balance

A calibration step at the start of each session sets your personal baseline so feedback is relative to you, not a generic average.

### Argument Analysis & Adversarial Questions
After you speak, the AI reads your full transcript and identifies the weakest claim you made — the one with the least supporting evidence. It then fires a targeted adversarial question at you mid-session. The question is scenario-aware:
- In a **pitch**: a skeptical investor challenging your numbers or market assumptions
- In an **interview**: a hiring manager probing your vague answers
- In a **presentation**: an audience member questioning your logic

### Live Coaching Tips
Short, blunt coaching tips are delivered mid-session via audio (ElevenLabs TTS). Tips reference your actual words and are triggered by whichever signal is currently weakest — filler words, pace, or engagement drop.

### Post-Session Breakdown
A full session report generated by LLM includes:
- Overall score (0–100)
- Timestamped high and low moments with transcript snippets
- Top strengths and specific improvements
- Focus area for your next session
- Argument feedback on the claim you made and how you handled the challenge question

### ASI:One Follow-Up Chat
The Podium coach agent is registered on Fetch.ai Agentverse. After your session, the "Ask a follow-up" box sends your questions directly to the agent via its REST endpoint. The agent also accepts messages through ASI:One, so anyone can chat with it without running the app.

## Agent Architecture

Podium is built as a **multi-agent system** using the [Fetch.ai uAgents framework](https://fetch.ai/docs):

| Agent | Role |
|---|---|
| `coach_agent` | Agentverse entrypoint — Chat Protocol + REST endpoints for ASI:One |
| `speech_agent` | ElevenLabs STT transcription, filler word detection, WPM |
| `vision_agent` | Webcam frame analysis — eye contact, posture, expression |
| `fusion_agent` | Combines speech + vision into a single engagement score |
| `audience_agent` | Drives avatar emotional states based on engagement |
| `argument_agent` | Extracts claims, finds weakest one, generates adversarial question |

All agents communicate through a FastAPI backend over WebSocket, with the frontend receiving real-time updates every second.

## Getting Started

### Prerequisites
- Python 3.11+
- Node.js 18+ and pnpm
- ElevenLabs API key
- Groq API key
- ASI:One API key (`sk_...` from [asi1.ai](https://asi1.ai))

### Setup

```bash
git clone https://github.com/jss0218/SpeakBetter.git
cd SpeakBetter

python3 -m venv venv
source venv/bin/activate
pip install -r podium/requirements.txt

cd frontend && pnpm install && cd ..
```

Create `podium/.env`:

```env
ELEVENLABS_API_KEY=your_key
ELEVENLABS_STT_MODEL_ID=scribe_v2
GROQ_API_KEY=your_key
GROQ_MODEL=llama-3.3-70b-versatile
ASI1_API_KEY=your_key
```

### Running

```bash
# Terminal 1 — FastAPI backend
PYTHONPATH=. uvicorn podium.main:app --port 8001 --reload

# Terminal 2 — Coach agent (Agentverse + ASI:One)
PYTHONPATH=. python podium/agents/coach_agent.py

# Terminal 3 — Frontend
cd frontend && pnpm dev
```

Open `http://localhost:5173`.

## Agentverse Integration

The `coach_agent` is live on [Agentverse](https://agentverse.ai) under **podium-coach-agent**. It uses the standard Chat Protocol (`uagents_core.contrib.protocols.chat`) so it's automatically compatible with ASI:One.

**REST endpoints** (when running locally):
```bash
# Health check
curl http://localhost:8000/rest/get

# Ask a coaching question
curl -X POST http://localhost:8000/rest/post \
  -H "Content-Type: application/json" \
  -d '{"question": "How do I stop saying um?"}'
```

Anyone with an ASI:One account can find **podium-coach-agent** in the marketplace and get public speaking coaching without running the app locally.
